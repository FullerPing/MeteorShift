# Rebirth icons

Three original, transparent 64 × 64 SVGs. All use the same 5-unit stroke, rounded caps/joins and `currentColor`, with no fonts, scripts, filters, external dependencies or embedded bitmaps.

- `rebirth-reset.svg`: simplest reset mark.
- `rebirth-cycle.svg`: paired arrows for a repeating progression loop.
- `rebirth-spark.svg`: reset with a spark for rebirth/prestige; recommended for the game HUD.

Inline SVGs inherit CSS `color`. For an image file or raster export, replace `currentColor` with the desired hex color, or set `color` on the SVG root. Transparent white PNG exports are included for image-based UI. These files do not change the active Roblox HUD or its uploaded assets.
