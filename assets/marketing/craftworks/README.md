# Craftworks: Meteor Mining artwork

Two matching directions:

- **Molten Impact**: orange meteor fissures, teal pickaxe, gold armored miner.
- **Crystal Rush**: cyan crystal meteor, purple armored miner, refinery and collection bars.

Each set includes a 512 × 512 PNG icon and a 1920 × 1080 PNG thumbnail. The matching SVG files are editable vector masters; drag them onto a Figma canvas or open them in Inkscape, Affinity Designer, or Illustrator. Art uses named groups and individual paths. Lettering is outlined Fredoka One to preserve the appearance without font installation. There are no embedded bitmap images.

`*-set-preview.png` files are comparison boards, not upload files. The ZIP contains the four upload PNGs, their four SVG masters, this readme, and the font license.

The original illustrations and SIL Open Font License are in `../vector-art/`. The authored compositions can be rebuilt with `tools/build-craftworks-molten.cjs` and `tools/build-craftworks-crystal.cjs` from the repository root, using the bundled Node runtime. Comparison boards are built with `tools/build-craftworks-previews.cjs`.

Upload dimensions follow Roblox's [icon guidance](https://create.roblox.com/docs/production/publishing/experience-icons) and [thumbnail guidance](https://create.roblox.com/docs/production/publishing/thumbnails). PNG exports were checked at their full dimensions and the icons at 150 × 150.
