# Craterworks vector artwork

The final matching assets are one directory above this folder:

- `craterworks-icon-vector.svg` — 512 × 512 editable vector master.
- `craterworks-icon-vector.png` — 512 × 512 upload export.
- `craterworks-thumbnail-vector.svg` — 1920 × 1080 editable vector master.
- `craterworks-thumbnail-vector.png` — 1920 × 1080 upload export.

Drag the SVG masters onto a Figma canvas, or open them in Illustrator, Affinity Designer, or Inkscape. The artwork consists of named groups and vector paths. Ungroup a section to adjust its individual shapes. Lettering is outlined to preserve its appearance without font installation.

The shared source pieces in this folder include the meteor, pickaxe, miner, crater landscape, and refinery loop. They contain no raster imagery, generated bitmap assets, or blur filters. The original generated PNG versions remain separate as `*-v1.png`.

The refinery drawing follows hopper → input conveyor → refinery → output conveyor → collection bars. The thumbnail keeps essential lettering in the upper area.

Typography is [Fredoka One by Milena Brandao](https://github.com/librefonts/FredokaOne), the same family used by the game's HUD. The original TTF and its SIL Open Font License are included in `fonts/`; the font was obtained from the [Pimoroni font package](https://github.com/pimoroni/fonts-python/tree/master/font-fredoka-one/font_fredoka_one/files).

Figma MCP created a blank file during this task, but its Starter-plan tool limit blocked the composition write. The delivered SVG and PNG files are the completed artwork.
